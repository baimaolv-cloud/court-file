# 诉讼策略决策框架

## 为什么需要决策框架

诉讼文书制作中，最浪费时间的不是写，而是反复讨论已经决定的问题。典型的：
- "AIDC设备赔不赔？" → 讨论了三遍，结论都是不赔
- "商标费算不算？" → 讨论了两遍，最终剔除
- "消费者要不要惩罚性赔偿？" → 讨论了两遍，最终删除

**根本原因**：没有在决策做出时立即记录，导致后续重新审视时重新论证。

---

## 四类决策分类

每个索赔/论证项必须归入以下四类之一：

| 类别 | 含义 | 写作位置 | 金额 | 示例 |
|------|------|----------|------|------|
| **索赔项** | 写入诉讼请求，有明确金额 | 诉讼请求+事实与理由 | ✓ | 可期待利益161,318.8元 |
| **论证项** | 写入事实与理由，无独立金额，支撑索赔 | 事实与理由 | ✗ | 腾讯低于成本价销售（新反法第14条） |
| **保留项** | 本案不主张，但明确保留另行主张的权利 | 事实与理由末段注明"保留另行主张" | ✗（本案） | 分付年化16.6%保留另行主张 |
| **剔除项** | 不写入诉状，记录决策理由备查 | 仅记录在决策日志 | ✗ | 商标费10,000元剔除（系护城河证明非损失） |

## 决策日志格式

每次做出策略决策，在工作区文件（如 `memory/YYYY-MM-DD.md`）中记录：

```markdown
### 策略决策：[简述问题]

- **日期**：2026-05-23
- **问题**：AIDC设备45,069元是否列入赔偿？
- **结论**：**剔除**（不列入赔偿）
- **理由**：AIDC系第三原告正常经营设备投入，非被告侵权直接损失，证据链弱
- **分类**：剔除项
- **影响**：标的额从30,253,XXX调减至30,188,XXX
```

## 策略决策检查清单

在撰写诉讼请求时，对每个可能索赔的项目过一遍：

```
□ 该损失是否由被告侵权行为直接导致？（因果关系）
□ 该损失是否有充分证据支撑？（证据链）
□ 索赔该金额是否可能被对方反驳且无法回应？（抗辩风险）
□ 索赔该金额是否影响主要诉求的严肃性？（策略权重）
□ 该损失是否已有其他渠道救济？（替代途径）
```

- 5个✓ → 索赔项
- 因果关系成立但证据弱 → 论证项（支撑其他索赔）
- 本案主张风险大但权利存在 → 保留项
- 因果关系不成立或影响主诉 → 剔除项

## 金额调减决策树

```
该金额是否由侵权直接导致？
├── 是 → 证据是否充分？
│   ├── 是 → 索赔项 ✓
│   └── 否 → 能否转为论证项？
│       ├── 是 → 论证项
│       └── 否 → 保留项（保留另行主张）
└── 否 → 是否与本案相关？
    ├── 相关 → 论证项（辅助论证）
    └── 不相关 → 剔除项
```
