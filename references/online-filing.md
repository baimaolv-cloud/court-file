# 网上立案指南

## 浙江法院网上立案

### 入口
- **浙江法院网**：https://www.zjcourt.cn
- **人民法院在线服务**：微信小程序搜索"人民法院在线服务"
- **浙江移动微法院**：微信小程序（部分法院已迁移至人民法院在线服务）

### 立案前材料清单

#### 必需材料
1. **起诉状**：PDF签字扫描件（打印→签名→捺印→扫描或拍照上传）
2. **身份证明**：
   - 原告身份证正反面扫描件
   - 原告为法人的：营业执照+法定代表人身份证明
3. **证据清单**：列明所有证据编号、名称、证明目的
4. **关键证据**：公证书、合同、支付凭证等PDF/图片

#### 可选材料
5. 委托手续（如有诉讼代理人）：授权委托书+律师执业证
6. 管辖依据材料（如被告住所地/合同履行地证明）
7. 诉前保全申请（如需）

### 操作步骤

1. **注册/登录**：浙江法院网或人民法院在线服务小程序
2. **选择立案类型**：民事一审→知识产权纠纷
3. **选择管辖法院**：杭州市中级人民法院→知识产权法庭
4. **填写当事人信息**：原被告姓名/名称/住址/联系方式
5. **填写诉讼请求**：与起诉状一致
6. **上传材料**：
   - 起诉状PDF（签字扫描件）
   - 身份证明
   - 证据材料（每个证据单独上传或打包上传）
7. **确认提交**

### 注意事项

- 起诉状**必须签名+捺印**，电子签名可能不被接受
- 证据材料建议按证据编号顺序命名文件
- 知识产权案件需选择对应案由（侵害商业秘密/不正当竞争/合同纠纷/消费者权益）
- 多案由合并的，主案由选"侵害商业秘密及不正当竞争"
- 提交后法院7日内审查是否立案
- 立案审查期间可能要求补正材料

### 案件受理费

- 知识产权案件：按标的额计算
- 标的额30,188,437.8元 → 案件受理费约191,842元（根据《诉讼费用交纳办法》）
- **减交/缓交/免交**：经济困难可申请司法救助

### 诉讼费速算

| 标的额区间 | 费率 | 速算加数 |
|-----------|------|---------|
| 0-1万 | 50元 | — |
| 1万-10万 | 2.5% | -200 |
| 10万-20万 | 2% | +300 |
| 20万-50万 | 1.5% | +1,300 |
| 50万-100万 | 1% | +3,800 |
| 100万-200万 | 0.9% | +4,800 |
| 200万-500万 | 0.8% | +6,800 |
| 500万-1000万 | 0.7% | +11,800 |
| 1000万-2000万 | 0.6% | +21,800 |
| 2000万以上 | 0.5% | +41,800 |

超过2000万部分 × 0.5% + 41,800 = 受理费

## 立案后续

1. **缴费**：收到受理通知书后7日内缴纳诉讼费
2. **举证期限**：法院指定举证期限，逾期证据可能不被采纳
3. **证据交换**：法院可能组织庭前证据交换
4. **开庭通知**：法院排期后发送传票
